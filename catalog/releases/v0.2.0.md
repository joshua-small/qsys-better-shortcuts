Better Shortcuts 0.2.0

Requires Q-SYS Mods Core 0.1.6 or newer within 0.1.x, Q-SYS Mod Manager 0.8+, and the exact supported Designer 10.5 build. The new package range enforces the dependency without changing historical 0.1.x packages or approvals.

Publishes the reviewed searchable command table, two-stroke recorder, explicit conflict overwrite, bulk default adoption, contextual adapters and effective native menu hints. Core remains the sole owner of shortcut registration, dispatch and persistence. Existing personal bindings and unrelated alternatives are preserved; recording and Preferences edits retain their shared save/cancel draft.

Recorded acceptance includes physical recorder/save, populated floating Component Controls, docked Monaco/Legacy editors, native property fields, native F5/F6/F7 and editing icon-menu hints/clicks. These results retain their original version and physical/automated attribution. Detached Actipro windows remain unsupported; additional commands, browser hosts and runtime UCI PopupTool acceptance remain in issue #2, with proposed new actions in issue #4. This packaging release adds no new Designer or hardware acceptance.
